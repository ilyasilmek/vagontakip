E2E tests run against the actual local Cloudflare Worker and the built React PWA.
They create temporary `e2e_` records and users, then remove those exact IDs in
cleanup. Existing application records are never changed. Remote server URLs are
rejected by the Playwright configuration.

Prepare local configuration with `npm run setup:local`, build with
`npm run build`, and start `npm run dev:api`. In another terminal run
`npm run test:e2e`. The ignored `.local/test-credentials.json` generated by local
setup supplies the administrator login. Passwords and cookies are not logged;
browser traces, screenshots and videos are disabled.

The tests cover two independent phone sessions sharing changes, stale-write
conflicts, administrator editing and deletion, ordinary-user restrictions,
same-origin request protection, password reset, account disabling and logout.
Browser checks cover the phone layout, accessible forms, search, a real XLSX
download, install icons, static service-worker caches and read-only offline
reloads.

Login protection limits repeated attempts. For isolated repeated test runs, start
the development server with a new ignored `--persist-to .wrangler/e2e-state-N`
directory rather than changing production login protection or deleting the
ordinary development state. Chromium at `/usr/bin/chromium` is reused when
available; elsewhere install the Playwright Chromium browser first.
